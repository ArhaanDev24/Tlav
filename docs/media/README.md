# Media

Everything here was captured from real runs, not mock-ups.

| File | What it is |
|---|---|
| `setup.gif` / `.mp4` | A real `tlav` run on a 16 GB, 4-core Linux PC, recorded byte for byte in a pseudo-terminal and replayed in xterm.js. The one-minute speed test is sped up 7×. |
| `chat.gif` / `.mp4` | The terminal chat from the same session: Qwen3.5 9B answering live at 3.4 tokens/s. |
| `cluster.gif` / `.mp4` | Two `tlav worker`s joining, a model split across 3 computers, and a chat on the split model. |
| `web-chat.gif` / `.mp4` | Tlav's web chat served by llama-server, with Qwen2.5 3B answering at 3.8 tokens/s. |
| `web-light.png`, `web-dark.png`, `web-phone.png` | The web chat in both themes and on a phone. |
| `website.png`, `site-fit.png`, `site-cluster.png` | The website in `site/`. |
| `banner.svg`, `icons/*.svg` | Pixel artwork matching the terminal welcome logo. The banner animates. |
| `social.png` | 1280×640 social preview card. |

GIFs are 880 px wide at 10–12 fps; MP4s are H.264 at 1600 px.
