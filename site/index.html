02 · One command

Your old computer isn't dead. It's waiting.

Run tlav setup and walk away. Five steps happen in order, and each one is checked before the next.

01

Read the machine

RAM, CPU cores and instruction sets, graphics, free disk. Windows, macOS or Linux, from netbooks to towers.

02

Measure real speed

On a CPU, words come out as fast as memory can feed the model. Tlav measures it in seconds and calibrates against real runs.

03

Pick the best model

Every model and size is weighed against your RAM and speed, from the built-in catalog or any model on Hugging Face.

tlav recommend
04

Shrink it, then check it

Weights go from 16 bits to about 5. Tlav compares the result with the original and rejects anything that loses more than 3%.

05

Start chatting

A chat page opens in your browser, plus an OpenAI-compatible API for your apps. Nothing leaves your computer.

tlav setup
03 · Cluster mode

Two old laptops. One bigger brain.

Run tlav worker on a spare machine. Tlav finds it on your home network and splits the model's layers between both, so their memory adds up.

Qwen3 30B · 48 layers · ~21 GBeach word passes through both
iMac, 16 GBlayers 1–24 · runs the chat
Laptop, 16 GBlayers 25–48 · runs tlav worker
Same answersSplit across three machines, the model gave word-for-word the same reply as on one.
Bigger, not fasterEvery word passes through each machine in turn. Use it to run a smarter model.
Home network onlyUse a cable if you can. Workers have no password, so keep them off public Wi-Fi.
