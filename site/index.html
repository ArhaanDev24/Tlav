How it works

Your old computer isn't dead. It's waiting.

One command looks at what your machine has, picks the smartest model it can run well, shrinks it to fit and starts it. No guides, no guessing which model will crash.

Step 1 · Detect

It reads your machine

RAM, CPU cores, AVX2 support, graphics and free disk. Works on 2010-era Intel Macs, ThinkPads and old towers with Windows, macOS or Linux.

tlav doctor
Step 2 · Benchmark

It measures real speed

On a CPU, words come out as fast as memory can feed the model. Tlav measures that in seconds and calibrates itself against real runs.

Step 3 · Pick

It finds the best model

Every model and size is weighed against your RAM and speed, from the built-in catalog or any model on Hugging Face. You get the smartest one that still feels responsive.

tlav recommend
Step 4 · Compress

It shrinks it, then checks it

Weights go from 16 bits to about 5, so a bigger, better model fits. Tlav tests the result against the original and rejects anything that loses more than 3%.

Step 5 · Run

You start chatting

A chat page opens in your browser, plus an OpenAI-compatible API for your apps. Everything stays on your computer.

tlav setup
Cluster mode

Two old laptops. One bigger brain.

Run tlav worker on your spare machines. Tlav finds them on your home network and splits the model's layers between them, so their memory adds up. Two 16 GB computers can run Qwen3 30B, which neither could hold alone.

Same answersA model split across three machines gave word-for-word the same reply as on one.
More memory, not more speedEach word passes through every machine, so you get a bigger model, not a faster one.
Home network onlyUse Ethernet if you can. Workers have no password, so keep them off public Wi-Fi.
