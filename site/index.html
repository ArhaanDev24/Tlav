Don't throw it out. Wake it up

Install once. Tlav picks, shrinks and runs the right model for the computer in front of you.

View on GitHub Free and open source
  1. 1Install

    macOS and Linux. On Windows, run install.ps1 in PowerShell.

    git clone https://github.com/ArhaanDev24/Tlav && cd Tlav && ./install.sh
  2. 2Start

    Measures your machine, picks the best model and compresses it to fit.

    tlav
  3. 3Chat

    In your terminal or your browser, your choice each time. Nothing leaves your computer. Next time, just type tlav.
