Don't throw it out. Wake it up

Install once. Tlav picks, shrinks and runs the right model for the computer in front of you.

View on GitHub Free and open source
  1. 1Install

    macOS and Linux. On Windows, run install.ps1 in PowerShell.

    git clone https://github.com/ArhaanDev24/Tlavv && cd Tlavv && ./install.sh
  2. 2Set up

    Measures your machine, picks a model and compresses it.

    tlav setup
  3. 3Chat

    Your private AI opens at localhost:8080. Nothing leaves your computer.
